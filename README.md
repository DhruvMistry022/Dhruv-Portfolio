# Dhruv Mistry - Professional Profile Website

A responsive personal portfolio website using HTML, CSS and JavaScript.

## Run the website
1. Extract this ZIP file.
2. Open the `index.html` file in Chrome, Edge or Firefox.
3. No installation or server is required.

## Before publishing
Open `index.html` and replace:
- `your.email@example.com` with your real email address.
- The sample GitHub, LinkedIn and Instagram profile links with your profile URLs.
- Project descriptions or technology lists if you want to update them.

## Colour palette
- Jet Black: `#0A0A0A`
- Cerulean Blue: `#007BA7`
- Neon Rose: `#FF2D95`

## Files
- `index.html` - website content
- `style.css` - responsive design and colour theme
- `script.js` - mobile navigation and current year
